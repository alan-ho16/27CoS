# Chambers of Sin (27CoS)

A browser-based dungeon-clearing RPG built as a Single-Page Application (SPA) with React, TypeScript, and Vite.

## Features

- **Turn-Based RPG Combat:** Pokémon-inspired battle HUD with live HP bars, turn logs, and action commands -- temporarily: (`FIGHT`, `GEAR`, `TOWEL`, `RUN`).
- **Equipment Loadouts:** Equip tools to stack stat bonuses.
- **Instant Navigation:** Seamless screen transitions between the Main Menu, Login/Account screens, and Dungeon Encounters with zero page reloads.

## Tech Stack

- **Framework:** React + TypeScript
- **Build Tool:** Vite
- **Styling:** CSS Modules

---

## Local Setup & Development

### Prerequisites

Make sure you have [Node.js](https://nodejs.org/) (v18 or higher recommended) installed on your machine.

npm install
npm run dev
